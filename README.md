# stock-data-web

銘柄コードを入力すると、直近4か月の株価・テクニカル指標のチャートを表示するStreamlitアプリです。

## 機能

- 日足ローソク足と5日・25日・75日の単純移動平均線（SMA）
- 出来高（株価の下に棒グラフ表示）
- RSI14（下段に表示、30・70の目安線あり）
- ADX14、+DI14、-DI14（同じパネルに表示、ADXの25を目安線で表示）
- チャート上部に銘柄コードと銘柄名を表示（Yahoo FinanceのlongName / shortName等を利用）
- チャートの拡大・縮小、マウスオーバーによる各日の値の確認
- 休場日の空白を除去したチャート表示
- 日本株の4文字コードには自動で `.T` を付ける。指数・先物等のYahoo Financeシンボルも入力可能
- 株価の取得結果を5分間、銘柄名の取得結果を1時間キャッシュ

テクニカル指標は `yamaccu/marketdata` と同じ計算方式（RSIは14期間、ADX・DIはWilder方式）を採用しています。75日移動平均線やADXが表示初日から計算できるよう内部で過去1年分の日足を取得し、表示範囲を直近4か月に絞っています。

銘柄名はYahoo Financeの提供情報に依存するため、名称が取得できない場合は銘柄コードのみ表示します。また、Yahoo Financeに登録されている名称の言語がそのまま使われます。

## 起動

`pip install -r requirements.txt`

`streamlit run app.py`
