# stock-data-web

銘柄コードを入力して、直近4か月の株価チャートを表示するStreamlitアプリです。

## 機能

- 日足ローソク足と出来高を上下2段のチャートに表示
- 5日、25日、75日の単純移動平均線（SMA）
- チャートの拡大・縮小やマウスオーバーによる価格確認
- 休場日の空白を除去したチャート表示
- 日本株4文字コードは自動で `.T` を付与（Yahoo Financeの他のシンボルも指定可能）
- 取得結果を5分間キャッシュ

75日移動平均線を表示開始時点から計算するため、内部では過去1年の日足を取得します。チャートに表示するのは直近4か月です。

## 起動

`pip install -r requirements.txt`

`streamlit run app.py`
