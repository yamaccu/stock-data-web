# stock-data-web

銘柄コードを入力すると、日足と1時間足の株価・テクニカル指標を縦に並べて表示するStreamlitアプリです。

## 機能

- 日足ローソク足と5日・25日・75日の単純移動平均線（SMA）
- 日足の下に1時間足チャートを追加（ローソク足・MA5/25/75・出来高・RSI14・ADX14・+DI14・-DI14）
- 1時間足は直近60日分を取得し、最初は直近14日を表示。Panで過去へ移動できる
- 出来高（株価の下に棒グラフ表示）
- RSI14（下段に表示、30・70の目安線あり）
- ADX14、+DI14、-DI14（同じパネルに表示、ADXの25を目安線で表示）
- 楽天証券の売買履歴CSVを任意でアップロード（売買マーカーは日足のみ。1時間足には表示しない）
- チャート上部に銘柄コードと銘柄名だけを表示（描画期間・約定件数の説明は省略）
- 初期表示は直近3か月。Pan（ドラッグ）で過去の値動きを確認（半年分のデータを描画）
- 買いは11pxの小さな上向き三角形（▲）、売りは11pxの下向き三角形（▼）で表示（グラフ上は数量・価格の文字表示なし）
- グラフをタップ／ホバーした際の詳細表示には、買い・売りの約定価格を表示。同日・同方向の複数約定は数量加重平均価格を表示
- 同日・同方向の複数約定は数量を合算して1つの三角形にまとめる
- CSVを指定しない場合は売買履歴なしで通常のチャートを表示
- チャートの拡大・縮小、マウスオーバーによる各日の値の確認
- 休場日の空白を除去したチャート表示
- 日本株の4文字コードには自動で `.T` を付ける。指数・先物等のYahoo Financeシンボルも入力可能
- 株価の取得結果を5分間、銘柄名の取得結果を1時間キャッシュ

テクニカル指標は `yamaccu/marketdata` と同じ計算方式（RSIは14期間、ADX・DIはWilder方式）を採用しています。日足は内部で過去1年分を取得して半年分のグラフを描画し、直近3か月を初期表示します。1時間足は過去60日分のデータを描画し、直近14日間を初期表示します。どちらもPan操作で過去へ移動できます。移動平均の5・25・75は各足の本数で計算します（1時間足のMA75は75本の1時間足の平均であり、75日の平均ではありません）。1時間足の日時は日本時間で表示します。1時間足の取得に失敗した場合でも、日足は表示します。

売買履歴CSVでは「約定日」「銘柄コード」「売買区分」「数量［株］」「単価［円］」を使用します。表示中の銘柄と一致する取引を約定日に配置します。マーカーの縦軸位置にはCSVの約定単価を使用します。同日・同方向に複数の約定がある場合は、数量加重平均した約定価格に1個の三角形を置きます。マーカー上に数量や価格の文字は表示しません（タップ時の詳細には約定価格を表示）。UTF-8とShift-JIS（CP932）のCSVに対応します。CSVは表示時にメモリ上で読み込み、GitHubへ保存しません。

銘柄名はYahoo Financeの提供情報に依存するため、名称が取得できない場合は銘柄コードのみ表示します。また、Yahoo Financeに登録されている名称の言語がそのまま使われます。

## 起動

`pip install -r requirements.txt`

`streamlit run app.py`
